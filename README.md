# Data Engineer Learning

A structured learning tracker for building practical Data Engineering skills through:

- Rapid multiple-choice practice
- AI-generated code review questions
- Short debugging exercises
- Micro-practical tasks
- Spaced review of weak topics
- Continuous mastery tracking

## Learning Loop

1. Read `tracker/data_engineer_learning_tracker.md`
2. Generate a 20-question session based on weak and unpracticed topics
3. Answer one question at a time
4. Record mistakes and mastery changes
5. Save the session under `sessions/`
6. Update the tracker and mistake log

## Main Skill Areas

- SQL
- Python
- PostgreSQL / relational databases
- ETL / ELT and pipeline design
- Data modeling
- Data quality and observability
- APIs and ingestion
- Git / GitHub
- CI/CD
- Orchestration
- Data warehouse / lakehouse fundamentals
- Spark / PySpark fundamentals
- Cloud and container fundamentals

## Practice Format

Default session: **20 questions**

- 70% rapid multiple-choice / concept judgment
- 20% code reading, debugging, or AI code review
- 10% micro-practical

The goal is not memorizing syntax. The goal is to identify correct designs, detect bad code, explain trade-offs, and make reliable engineering decisions.
